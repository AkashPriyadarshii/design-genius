The Philosophical Line

Why the web is drowning in an aesthetic monoculture.

"Every standard AI design prompt ships the exact same average: a centered hero, three feature cards, and a purple gradient. The average of everything is nothing."

That sameness is structural, not a lack of effort. When an LLM designs from its training weights, it statistically reproduces the mean of the modern SaaS web.

design-genius destroys this failure mode by physically barring the agent from designing from memory. It forces the model to open files, read real token blocks from disk, derive physical causal lines (like sealing-wax vermillion from Indian gazette stamps), and prove mathematical hue separation before writing a single line of code.

The 10-Dimension Implementation Standard

A specification is only as good as its downstream implementation. design-genius produces specs that are strictly verified by akash-design-engineering via node bin/audit.mjs.

Dimension Physical Standard Engine Verification Rule
1. Concentric Geometry R_inner = max(0, R_outer - p) Zero arbitrary border-radii. Inner elements strictly calculate radius based on parent padding to eliminate visual pinching.
2. Analytical Springs F = -k·x - c·v (RK4 Integrator) Replaces default CSS transitions with custom cubic-beziers or analytical ODE kinetic spring formulas under 200ms.
3. Causal Pigments OKLCH with Anchor Chroma ≥ 0.006 Bans pure digital RGB voids. Color tokens must trace to a physical real-world object with verifiable causal receipts.
4. Procedural Grain Ra ≈ 2.4μm Micro-Noise Substrates must simulate physical materials via procedural SVG turbulence filters, preventing sterile digital flatness.
5. Sensory Sound 12ms High-Q Bandpass (Optional) Procedural audio micro-clicks synthesized via Web Audio API. Strictly toggleable and disabled for silent reading modes.
6. Fluid Typography clamp(min, val + vw, max) Enforces the 2+1 font ceiling. Strict typographic scale using proportional modular ratios with tabular lining numbers.
7. Spatial Grid 4px / 8px Rhythmic Ladder No arbitrary margins or paddings. Every spatial boundary conforms to the strict 4px grid with 1px continuous hairlines.
8. Accessible Contrast WCAG 2.2 AAA Compliance 14.2:1 contrast ratio for body ink on archival paper substrate; ≥ 5.4:1 contrast for all interactive accent buttons.
9. Semantic DOM Accessible Semantic Landmarks Full JSON-LD structured metadata, screen-reader focus traps, and logical section hierarchies with zero div-soup.
10. Slop Scanner Deterministic Rejection Gate Instant build failure if unauthorized buzzwords (generic marketing terms), text emojis, or 3-card generic rows are detected.
