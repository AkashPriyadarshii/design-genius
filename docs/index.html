The design skill that never repeats itself.

A Claude Code skill that writes a genuinely unique, non-slop DESIGN.md for any design task. It reads a local library of real design systems, fuses two or three, and emits one bespoke spec with real tokens. It never designs from the model's memory of "good design."

$ cat ./pipeline

./pipeline4 stages
1.Harvest intent #harvestOne sharp question, never a form. Audience, mood, brand voice, platform, the one constraint that matters.
2.Read-gate #readLists the design systems on disk, picks 2–3 structurally different ones, reads the real token blocks. Designing without reading is vibecode.
3.Fuse #fuseFuses two into skeleton and texture, borrows single tokens or levers from one or two more. Every borrow is named — the spec carries its own receipts.
4.Emit #emitA buildable DESIGN.md. Real token values, full type scale, spacing, radius, motion, the signature detail. No --accent: pick me. Hand it to codegen.
